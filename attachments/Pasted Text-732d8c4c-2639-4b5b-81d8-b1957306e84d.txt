یک نسخه جدید و کامل از پروژه NOVA AI بساز.

نام برنامه:
NOVA AI
دستیار هوشمند فارسی

هدف:
یک چت‌بات هوش مصنوعی فارسی برای اندروید که مدل اصلی آن به‌صورت آفلاین روی گوشی اجرا شود.

مدل:
Gemma 3 4B Persian
فایل مدل:
gemma-3-4b-persian-v0.Q4_K_M.gguf

الزامات اصلی:
1. مدل باید واقعاً با llama.cpp اجرا شود، نه اینکه فقط یک فایل GGUF داخل پروژه قرار بگیرد.
2. اجرای مدل باید از طریق Native C++ و JNI به Kotlin/Android متصل شود.
3. رابط کاربری چت با React + TypeScript/TSX باشد.
4. پروژه با Vite/Capacitor قابل ساخت برای Android باشد.
5. ABI اصلی فقط arm64-v8a باشد.
6. برای اجرای مدل از CPU استفاده شود.
7. مدل به‌صورت OBB یا روش مناسب خارج از APK نگهداری شود تا حجم APK بیش از حد بزرگ نشود.
8. برنامه بعد از نصب بتواند مدل را از محل صحیح پیدا و load کند.
9. اگر مدل وجود نداشت، برنامه نباید crash کند؛ وضعیت «مدل نصب نشده» را نمایش دهد.
10. یک Bridge کامل بین JavaScript و Native C++ ایجاد کن:
   - initializeModel
   - isModelReady
   - generateResponse
   - releaseModel
11. پاسخ مدل باید به‌صورت واقعی از Gemma تولید شود.
12. قالب گفت‌وگوی Gemma را درست اعمال کن.
13. تنظیمات دما، تعداد توکن خروجی و context را در یک محل مشخص قرار بده.
14. یک رابط چت تمیز و فارسی RTL بساز.
15. پشتیبانی از متن فارسی و Unicode کامل باشد.
16. جست‌وجوی وب در نسخه اولیه وجود نداشته باشد.
17. سیستم پرداخت در برنامه وجود داشته باشد، اما اطلاعات محرمانه پرداخت یا کلیدهای خصوصی داخل APK قرار نگیرد.
18. ساختار پرداخت را طوری طراحی کن که بعداً بتوان درگاه رسمی فروشگاه اندرویدی/پرداخت موردنظر را به آن متصل کرد.
19. وضعیت Premium/خریداری‌شده از سمت برنامه قابل بررسی باشد.
20. کد پرداخت را با یک interface/service جدا از UI طراحی کن تا بعداً بتوان SDK واقعی فروشگاه را بدون بازنویسی برنامه اضافه کرد.
21. هیچ API Key، Secret Key یا اطلاعات حساس را داخل GitHub و APK قرار نده.
22. پروژه باید GitHub Actions برای ساخت APK داشته باشد.
23. Workflow باید وابستگی‌های Android SDK، NDK، CMake و llama.cpp را نصب/دریافت کند.
24. در صورت وجود مدل در مسیر مشخص، امکان ساخت OBB مدل را فراهم کن.
25. در صورت نبود مدل، APK همچنان قابل build باشد ولی اجرای مدل وضعیت مناسب نمایش دهد.
26. README کامل برای ساخت پروژه و اضافه‌کردن مدل بنویس.
27. هیچ قسمت مهمی را به‌صورت fake/stub باقی نگذار؛ مخصوصاً inference و Native Bridge.
28. کد را تمیز، قابل نگهداری و ماژولار بنویس.

مهم:
- هیچ ادعایی درباره تست‌شدن چیزی که واقعاً compile نشده نکن.
- اگر دانلود llama.cpp یا مدل در محیط ساخت لازم است، آن را در GitHub Actions انجام بده.
- فایل مدل را داخل GitHub commit نکن مگر اینکه صراحتاً لازم و از نظر حجم/مجوز مناسب باشد.
- در پایان پروژه باید یک APK قابل ساخت، Native inference واقعی، OBB مدل و ساختار آماده برای اتصال درگاه پرداخت داشته باشد.
- فقط کد کامل پروژه را بساز و فایل‌های لازم را تغییر بده؛ توضیحات اضافی و کد نمونه ناقص نده.
